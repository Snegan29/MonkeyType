# 🐒 MonkeyType Clone

A fast and responsive clone of [Monkeytype](https://monkeytype.com), the popular typing speed test app. This project replicates the typing experience with customizable settings, performance tracking, and engaging animations.

## 🚀 Features

- ⌨️ Real-time typing test interface  
- 📊 WPM, accuracy, character stats  
- 🎨 Custom themes & keyboard visuals  
- 🛠 Adjustable time/duration settings  
- 🔁 Restart and reset functionality  
- 🧪 Optional support for punctuation/numbers

## 🛠 Tech Stack

- **Frontend:** React.js, CSS
- **Deployment:** Vercel
